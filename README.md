# 拾信 · 飞书小组试用版

拾信归纳指定飞书群的文字消息。成员核对摘要后，可以确认个人待办、设置私聊提醒，在手机上查看按截止日期排列的时间轴。

## 在电脑上试用

需要 Node.js 24 和 pnpm。进入仓库目录后，在 PowerShell 中运行：

```powershell
pnpm install --frozen-lockfile --ignore-scripts
if (!(Test-Path .env)) { Copy-Item .env.example .env }
pnpm start
```

打开 <http://127.0.0.1:5300/>，选择 Alice 或 Bob 本地登录。在「群消息」中展开本地联调，输入测试通知，例如「作业：明天下午五点前提交实验报告」。到「消息中心」确认待办，再到「待办」和「时间轴」查看。默认示例使用本地模拟数据。

## 接入小组的飞书应用

按[飞书接入清单](飞书接入清单.md)配置企业自建应用、事件订阅、登录回调和授权群。把团队配置填入自己的 `.env`。应用凭证和群数据只保存在本地，仓库提供空白配置示例。

本地服务运行期间才能接收新群消息和发送提醒。手机需要访问能连通的服务地址。跨网络使用时需要持续运行的后台和 HTTPS 入口。

## 源码结构

| 路径 | 内容 |
| --- | --- |
| `public/` | 手机和电脑共用的网页 |
| `src/` | 飞书接入、消息归纳、登录、任务和提醒 |
| `tests/` | 消息、权限、待办和网页交互测试 |
| `scripts/` | 本地配置检查和联调工具 |

运行 `pnpm test` 检查代码。网页测试需要本机有 Playwright 和 Edge。消息归纳使用规则提取，使用者应在确认待办前核对原文和时间。
